# Rehabilitation Workflow

## Operating Views

Centre operations: admissions, discharges, occupancy, beds, leave, appointments, outstanding documentation, incidents and escalations.

Clinician: My Day, clients, sessions, tasks, documentation, assessments, treatment plans and MDT actions.

Nursing/residential: shift queue, medication, observations, incidents, handover, residents and leave.

## Core Workflow Patterns

Admission is a guided readiness workflow, not a collection of unrelated forms. Assessment is sectioned with draft/resume/review/sign/amendment states. Treatment plans move Draft -> Review -> Participation/Consent -> Approved -> Active -> Periodic Review -> Revised/Completed. Clinical records move Draft -> Review -> Sign -> Locked; corrections use amendment/addendum.

MDT has preparation, meeting and post-meeting phases. Discharge exposes blockers across clinical summary, medication reconciliation, risk plan, follow-up, documents, billing clearance and final review. Dashboards drill directly to actionable queues.
