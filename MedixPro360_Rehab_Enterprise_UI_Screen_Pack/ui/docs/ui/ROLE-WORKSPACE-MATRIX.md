# Role / Workspace Matrix

Roles are UX personas. Effective navigation must come from membership, active roles, permissions, entitlements and location scope.

| Workspace | Primary roles | Core work |
|---|---|---|
| Platform Operations | Super Administrator, Platform Support, Platform Security/Audit | tenants, subscriptions, entitlements, region, platform health, support access, audit, AI governance |
| Tenant Administration | Tenant Administrator, Quality/Compliance, Read-only Auditor | users, invitations, roles, locations, configuration, consent, retention, integrations, audit |
| Centre Operations | Centre Administrator, Management/Operations, Front Desk | admissions, discharges, occupancy, beds, appointments, staffing, alerts, operational queues |
| Intake & Admissions | Intake Coordinator, Reception, Care Coordinator, Clinician | referrals, duplicate match, eligibility, documents, consent, readiness, admission |
| Clinician Day | Clinical Director, Psychiatrist, Physician, Psychologist, Therapist, Social Worker, Dietitian | My Day, clients, appointments, tasks, documentation, reviews, MDT, treatment plans |
| Nursing Shift | Nurse, Medical Officer | medication due, observations, assigned clients, incidents, handover, escalation |
| Residential Shift | Residential Care Staff, Support Worker, Nurse | residents, checks, activities, leave, meals, incidents, handover, bed status |
| Home-Care Control Centre | Home-Care Coordinator, Care Manager, Centre Operations | visits, dispatch, unassigned/late/missed visits, caregiver capacity, escalations, documentation |
| Billing & Revenue | Billing/Accounts, Centre Administrator, Management | accounts, charges, invoices, payments, holds, discharge clearance |
| Inventory Operations | Inventory/Store Manager, Nurse, Centre Administrator | stock, batches, requests, issue/return, transfer, reorder, approvals |
| Client Workspace | all permitted tenant roles | longitudinal client context, tabs, actions, timeline, tasks, documents, consent |
| Client/Family Portal | Client, Family member | permitted appointments, tasks, assessments, documents, payments, communication |

Shared workspace templates should be permission-driven. Role differences should change visible data, actions and signing authority rather than create duplicate shells.

UI-1 includes demonstration profiles for Platform Super Admin, Tenant Administrator, Centre Administrator, Psychiatrist/Clinician, Nurse, Residential Care Staff, Home-Care Coordinator, Billing User and Inventory User. These profiles vary workspace, modules, permissions and location scope through the mock effective-access adapter.
