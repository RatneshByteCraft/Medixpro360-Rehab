# AI Embedding Map

AI is a cross-cutting assistance layer. It is not a 17-item feature menu.

| Existing AI capability | Owning workflow | New UX form | Role | Trigger | Human review |
|---|---|---|---|---|---|
| Clinical Documentation Assistant | therapy/clinical session | contextual assistant panel | clinician/therapist | session note draft | review, edit, sign |
| Voice / Transcript Review | clinical session | session drawer | clinician/therapist | transcript available | accept/edit/reject |
| Intake / Document Extraction | intake/admission | extraction review panel | intake coordinator | document upload | field-by-field confirmation |
| Client Journey Summary | Client Workspace | summary card with sources | permitted clinician/care coordinator | open client workspace | inspect sources |
| Clinical Record Copilot | Client Workspace | context action | clinician | explicit request | human decision |
| MDT Brief | MDT agenda | pre-meeting brief panel | MDT participants | meeting preparation | review and amend |
| Treatment Plan Draft Review | treatment plan | draft/review side panel | clinician/director | plan draft | approve/edit/reject |
| Assessment Trend Explanation | assessment history | trend explanation drawer | clinician | trend review | inspect evidence |
| Medication Intelligence | medication review | medication context panel | prescriber/pharmacist | reconciliation/review | clinical verification |
| Discharge Summary Review | discharge | blocker/review panel | clinician/care coordinator | discharge readiness | sign-off remains human |
| AI Handover | nursing/residential shift | handover assistant | nurse/care staff | shift handover | review before publish |
| Task Extraction | notes/intake/MDT | task confirmation list | care coordinator | source text processed | accept/edit/reject |
| Operational Analytics Copilot | operations analytics | query assistant beside report | management/operations | report question | inspect query/result |
| Evidence / Sources Viewer | any AI output | drawer | authorized user | evidence action | provenance visible |
| Report Incorrect Output | any AI output | modal/action | authorized user | user feedback | audit issue |

Every AI surface must show generated status, timestamp, model/provider/version, evidence/source links, limitations where meaningful, reviewer, decision and audit trail. AI never becomes the owner of clinical records.
