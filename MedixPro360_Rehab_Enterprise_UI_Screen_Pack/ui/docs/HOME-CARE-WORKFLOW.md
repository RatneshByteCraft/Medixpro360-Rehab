# Home-Care Workflow

Home care is a control-centre workflow, not a residential-location variant.

The coordinator workspace prioritizes today's visits, unassigned/late/missed visits, caregiver availability, client attention, documentation pending and escalations. Visit planning includes care package, skills/qualification fit, assignment, status, execution documentation and exception handling.

Caregiver administration shows availability, assigned clients, competencies, credentials, upcoming visits and documentation status. Client care plans, family communication, tasks, escalation and review are linked to the client workspace without duplicating canonical records.
